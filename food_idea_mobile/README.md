# Food Idea — мобильная версия для Qt 5.14

Проект переделан под **Qt 5.14** и рассчитан на запуск в Qt Creator с комплектом вроде:

- Desktop Qt 5.14.0 MinGW 64-bit
- Desktop Qt 5.14.0 MSVC 2017/2015 64bit

Основной вариант открытия — файл `food_idea_mobile.pro`. Также оставлен `CMakeLists.txt` для сборки через CMake.

## Запуск в Qt Creator

1. Распакуйте проект.
2. Откройте `food_idea_mobile.pro`.
3. Выберите установленный Qt 5.14 Kit.
4. Нажмите «Настроить проект».
5. Запустите проект кнопкой ▶.

## Android

В `.pro` предусмотрена Android-конфигурация через `ANDROID_PACKAGE_SOURCE_DIR`. Для сборки APK нужен Android Kit Qt 5.14 с настроенными Android SDK/NDK/JDK.

## Что внутри

- Qt Quick / QML интерфейс, адаптированный под мобильный экран.
- Меню на день.
- Рекомендации с учётом продуктов.
- Список продуктов с сохранением через QSettings.
- Просмотр рецептов.
- Добавление собственных рецептов с сохранением.
- Поддержка фотографии блюда.
